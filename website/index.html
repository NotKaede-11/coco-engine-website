01 // CORE ARCHITECTURE

Engineered for depth & speed.

Every module in Coco is designed in modern C++20 with cache locality, zero dynamic allocation during search, and vector SIMD intrinsics.

ARCH // 01 EVALUATION

768→512×2 NNUE Network

A dual-perspective neural network architecture transforming board squares into dual 512-dimension accumulators with clipped ReLU activations. Incrementally updated on every move.

  • Accumulator16-bit Integer Quantized
  • SIMD AccelerationAVX2 & AVX-512 Intrinsics
  • DeliveryEmbedded in Executable
ARCH // 02 SEARCH DYNAMICS

Alpha-Beta & PVS Framework

Principal Variation Search with iterative deepening, adaptive aspiration windows, Late Move Reductions (LMR), Singular Extensions, and Reverse Futility Pruning.

  • SelectivityNMP, RFP, SEE Pruning
  • Move OrderingTT Hash, MVV-LVA, Killers
  • History TablesContinuation & Counter-Move
ARCH // 03 REPRESENTATION

Magic Bitboard Movegen

64-bit Bitboard representations for all piece topologies. Sliding attack masks for rooks and bishops are computed in O(1) time using precomputed Magic Hash tables.

  • Move GenerationPseudo-legal with Filter
  • Slider LookupsFancy Magic Bitboards
  • Zobrist Hashing64-bit Polyglot Compatible
ARCH // 04 CONCURRENCY & ENDGAME

Lazy SMP & Syzygy Tablebases

Multi-threaded scaling via lockless shared Transposition Tables across all worker threads. Seamless endgame resolution via Syzygy 3-4-5-6 piece WDL and DTZ probing.

  • MultithreadingLazy SMP (Shared TT)
  • TablebasesSyzygy WDL & DTZ
  • ProtocolUniversal Chess Interface (UCI)
02 // EMBEDDED NEURAL NETWORK

Zero external weights. NNUE baked inside.

Every Coco release binary includes the complete 768→512×2 neural network compiled directly into the executable. There are no separate .nnue weight files to download, locate, or configure.

PLUG & PLAY
Immediate Neural Evaluation

Load the Coco binary directly into Cutechess, BanksiaGUI, Nibbler, or Arena. The engine immediately boots into full NNUE mode with zero missing-file errors.

HCE SEPARATION
No Silent HCE Fallback

Unlike engines that silently degrade to Handcrafted Evaluation (HCE) when missing weight files, Coco guarantees 100% neural evaluation by default in every tournament game.

OPTIONAL OVERRIDES
Custom Network Testing

Engine researchers and neural network trainers can still benchmark custom experimental weights anytime via the standard UCI EvalFile option.
