Set up your engine

  1. Download the executable for your operating system and CPU.
  2. Add it as a UCI engine in a chess interface such as Cutechess or Arena.
  3. For Chess960, select the variant and load a Chess960 starting position in your interface.

Test from a terminal

Start your Coco executable and enter these UCI commands.

uci
isready
position startpos
go movetime 1000

When Coco returns bestmove, enter quit.

Inside the engine

Coco uses neural evaluation to score positions, then searches move sequences to decide which line to play.

Read the 2.0 source

Embedded Ravager v3

The NNUE updates two 1,024-wide accumulators as pieces move. It uses mirrored king buckets, threat and pawn-pair inputs, and material-dependent output buckets. The original weights and evaluator come from erensh27.

Third-party notices

Search and parallel play

Alpha-beta search uses principal variation search, iterative deepening, and aspiration windows. Worker threads share a transposition table through Lazy SMP. Coco 2.0 also reuses valid cached cutoffs earlier and uses four-ply continuation history to order quiet moves.

Move generation and endgames

Magic bitboards handle sliding attacks, with PEXT available in BMI2 builds. Chess960 uses UCI Chess960 castling notation. Local Syzygy files enable win/draw/loss and distance-to-zero probing for up to six pieces.

Common questions

How do I install Coco in a chess GUI?

Download the Coco executable for your system, then add it as a UCI engine in a compatible chess GUI, such as Cutechess or Arena. The GUI provides the board and controls for playing or analyzing games.

Which Coco build should I download?

On Windows or Linux x86-64, choose the POPCNT build if your CPU supports POPCNT and SSE4.1. For Linux ARM64, choose the baseline ARM64 build. On macOS, choose Apple Silicon for an M-series Mac or an x86-64 build for an Intel Mac. See the CPU compatibility guide for the other builds.

How do I play Chess960 with Coco?

Select Chess960 in your UCI-compatible GUI and load a Chess960 starting position. Coco 2.0.0 supports Chess960 through the UCI_Chess960 option.

What rating does Coco have?

Coco 1.5.0 scored 3027 (±50 over 98 games) on CCRL 40/15. Coco 1.5.1 scored 2986 on CCRL Blitz. See the rating list links and the separate Coco 2.0 local match for the test conditions.
